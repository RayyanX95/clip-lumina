# ClipLumina v1.0.0: The Official Launch 🚀

Welcome to the first official release of **ClipLumina**, the high-performance, premium clipboard manager for macOS. This version marks our transition from a private prototype to a production-ready, open-source tool.

## ✨ What’s New

* 💨 **Rust-Powered Performance:** Built with Tauri 2.0 and Rust for near-zero background CPU and RAM usage.
* 🏠 **Minimalist Menu Bar UI:** A sleek, "Accessory Mode" interface that stays out of your way until you need it.
* 🧠 **Smart Content Detection:**
  * **Code Snippets:** Instant syntax highlighting for copied code.
  * **Web Links:** Previews with domain favicons.
  * **CSS Colors:** Visual previews for Hex, RGB, and HSL codes.
  * **Images & Files:** High-resolution thumbnails for local image files and system paths.

* ⚡ **Pro-Ready Features:**
  * **Auto-Paste:** Optionally paste content immediately upon selection.
  * **Auto-Hide:** The window dismisses itself automatically when focus is lost.

## 🔒 Privacy First

Your clipboard history stays **100% on your machine**. No telemetry, no tracking, and no cloud syncing.

## 🛡️ Open Source Release

We believe a clipboard manager should be a tool you can trust. As of this version, ClipLumina is officially **Open Source** under the **MIT license**. Explore the code, verify our security, or contribute to the core engine.

---

## 📦 Installation Instructions

1. **Download** the `ClipLumina_1.0.0_aarch64.dmg` asset below.
2. **Drag** ClipLumina to your `Applications` folder.
3. ⚠️ **Important:** Since this is an independent build, you must **Right-click -> Open** the app from your Applications folder the first time to bypass macOS Gatekeeper.
