Download for macOS v1.0.0 | Apple Silicon & Intel

Bypass "Damaged App" Warning

1

Drag to Applications

Once you download the DMG, drag the ClipLumina icon into your Applications folder.

2

Right-Click and Open

Do not double-click. Instead, Right-click (or Control-click) the ClipLumina icon and select Open.

3

Confirm Security Dialog

A message will appear saying macOS cannot verify the developer. Click the Open button to run the app anyway.

Why is this happening?

ClipLumina is open-source and hasn't been notarized by Apple's paid developer program yet. macOS warns you about any app downloaded from the internet that isn't signed. Your data remains 100% private and stays on your local machine.

Advanced: If the above doesn't work, run this in Terminal:

xattr -d com.apple.quarantine /Applications/ClipLumina.app
