## 🚀 The Release Roadmap

### 🧱 Stage 1: MVP (Available Now)

Our current focus is building the fastest, most lightweight clipboard engine for macOS.

- **Instant History**: Zero-latency polling in Rust.
- **Smart Thumbnails**: Preview images and links.
- **Auto-Paste Control**: Direct injection into your active apps.

### 🏢 Stage 2: Stable & Pro UI (Next Release)

**Model: One-time Lifetime License ($19)**
Transform ClipLumina into a professional workflow tool.

- **No Limits**: Store thousands of items without slowing down your Mac.
- **Smart Folders**: Auto-detect Code, Colors, and Links.
- **Pro Theming**: Deep customization and premium glassmorphism effects.
- **Advanced Search**: Find any clip from 3 months ago in milliseconds.

### 🧠 Stage 3: Lumina AI (Later Stage)

**Model: Optional Add-on Subscription**
Unlock the intelligence layer once the foundation is rock-solid.

- **AI Refactor**: Change code from Python to Rust or rewrite an email tone from the tray.
- **Context Summaries**: Summarize long copied text with a single click.
- **Natural Search**: "Find that address I copied from Slack yesterday afternoon."

---

## 💰 Why We Separate Pro UI from AI?

1. **Sustainability**: AI tokens cost money every time they run. By keeping AI as a separate stage/sub, we can offer the **Pro UI for a one-time price**!
2. **Privacy**: Pro UI features run 100% locally. AI features are optional for those who want web-connected intelligence.
3. **Maturity**: We want to make sure the app is perfectly stable (Stage 2) before we ask the AI brain to do heavy lifting (Stage 3).
