# Security Policy

## Reporting a Vulnerability

ClipLumina takes security very seriously. If you discover a security vulnerability, please do NOT open a public issue. Instead, please report it privately:

1. **Email**: ibrahim.alrayany@gmail.com
2. **Timeline**: We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Our Security Guarantees

- **No Data Collection**: We do not collect, store, or transmit your clipboard data.
- **Local Only**: All data remains on your physical device.
- **Sandboxed**: We follow Tauri security best practices, limiting filesystem access via scopes.
